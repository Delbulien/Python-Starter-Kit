Repository containing material to learn python feature


# 🛠️ Prerequisites – Development Environment Setup

This guide describes the successive steps to install the required tools so you can work on the Python training files in this repository.

> **Table of contents**
> 1. [Visual Studio Code](#1--install-visual-studio-code)
> 2. [Git](#2--install-git)
> 3. [Miniforge (Python)](#3--install-miniforge-python)
> 4. [GitHub account](#4--create-a-github-account)
> 5. [Using Git in VS Code](#5--using-git-in-visual-studio-code)
> 6. [Clone the repository](#6--clone-the-repository)

---

## 1. 🧩 Install Visual Studio Code

1. Go to the download page:
   👉 [Download Visual Studio Code](https://code.visualstudio.com/download?_exp_download=d53503e735)

   *Or search for "visual studio code" on Google.*

2. Download the setup executable and launch it.

> ⚠️ **Important:** do **not** install **Copilot**.

---

## 2. 🔧 Install Git

1. Follow this video tutorial if needed:
   🎥 [Git installation video (YouTube)](https://www.youtube.com/watch?v=7ouVv6PFZGc)

2. Download page:
   👉 [git-scm.com/install/windows](https://git-scm.com/install/windows)

3. Download the Windows executable and launch it.

**Installation options:**

- ✅ Select **"Use Visual Studio Code as Git's default editor"**
- ✅ Keep all the other options to their **default values**

---

## 3. 🐍 Install Miniforge (Python)

You will get Python from Miniforge.

1. Go to the download page:
   👉 [conda-forge.org/download](https://conda-forge.org/download/)

2. Select the **Windows** environment and launch the executable.

**Installation options:**

- ℹ️ *Additional info:* run the installation anyway if a warning appears.
- ✅ Choose **"Just me"** (only a local installation for the current user)
- ✅ Check **"Register Miniforge 3 as my default Python 3.14"**

---

## 4. 👤 Create a GitHub account

1. Go to:
   👉 [github.com](https://github.com/)

2. Need help? Follow this video tutorial:
   🎥 [How to create a GitHub account (YouTube)](https://www.youtube.com/watch?v=RnWDKWmaQ8s)

---

## 5. 📺 Using Git in Visual Studio Code

Follow this video tutorial to learn how to use Git directly in VS Code:
🎥 [How to use Git in VS Code (YouTube)](https://www.youtube.com/watch?v=twsYxYaQikI)

---

## 6. 📥 Clone the repository

1. Create a folder in your **Documents** (name it "Development" for example) where you are going to clone the current repository.

2. Clone the current repository with **VS Code** in the folder created in the previous step.

3. In VS Code, select **"Open in new window"**.

---

✅ **You're all set!** Your working environment is ready. You can now work on the Python training files in the repository.
